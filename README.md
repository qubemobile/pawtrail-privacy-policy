# PawTrail privacy policy

The PawTrail privacy policy, served by GitHub Pages at https://qubemobile.github.io/pawtrail-privacy-policy/.

This address is used in three places, so keep it stable:
- `PawTrailGame.PrivacyPolicyUrl` in the game (Settings → Privacy policy);
- the Play Console store listing;
- the AdMob GDPR message.

The site is plain HTML (`.nojekyll` turns off Jekyll).

## Publishing

In the repository's Settings → Pages, choose "Deploy from a branch", `main`, `/ (root)`.
